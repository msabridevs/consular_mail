# منظومة البريد القنصلي — فرانكفورت

مشروع كامل المصدر: React + Vite، قاعدة PostgreSQL وAuth في Supabase، ودالة استعلام على Vercel. التخزين في Supabase، والكود في GitHub، والاستضافة في Vercel. جميع واجهات العمل بالعربية والألمانية.

**لفصل الموظفين عن الجمهور: [التغييرات المطلوبة فقط](docs/SEPARATE_SITES_AR.md).**

للتثبيت الأول اتبع [دليل التنفيذ العربي](docs/SETUP_AR.md)، مع فصل الموقعين كما في الدليل أعلاه.

- الجمهور: `/`.
- الموظفون والقناصل: `/` على مشروع Vercel مستقل يضبط `VITE_APP_MODE=staff`؛ الواجهة تتغير بحسب الصلاحية.
- الجمهور: مشروع Vercel يضبط `VITE_APP_MODE=public` (وهو الافتراضي). لا رابط أو واجهة موظفين على الموقع العام.
- إنشاء القاعدة: `supabase/001_schema.sql`.
- إسناد الصلاحيات: `supabase/002_staff-template.sql`.
- متغيرات الاتصال: `.env.example`.
- دليل العمل والتشغيل: `docs/OPERATIONS_AR.md`.
- الاختبارات وحدود التحقق: `docs/VERIFICATION.md`.
- شرح التصميم والمصادر الرسمية: `docs/ARCHITECTURE.md`.

## ما الذي يعمل؟

| الوظيفة | التنفيذ |
|---|---|
| تسجيل الوارد | رقم الإرسال، اسم المرسل، القسم، المبلغ باليورو؛ توقيت الخادم تلقائي |
| تسليم القسم | تحديد ظرف أو عدة أظرف ثم تأكيد الاستلام؛ تتحول إلى قيد العمل |
| الملاحظات | عامة بالعربية والألمانية + ملاحظة داخلية منفصلة |
| إعادة البريد | تحديد الأظرف ثم تأكيد الإعادة بعد تسليمها فعليًا للإرسال |
| متابعة القنصل | أعداد الأقسام المصرح بها، الانتظار، الجاري، المعاد، المتأخر، متوسط المدة وسجل كل ظرف |
| استعلام الجمهور | رقم الإرسال فقط، مع حماية آلية؛ نتيجة محدودة دون الاسم أو المبلغ |
| الحماية | تحقق بخطوتين، فصل أقسام، وظائف قاعدة محددة، حظر الوصول المباشر للجداول، سجل تدقيق |
| التزامن | قفل صفوف ورقم نسخة؛ عملية جماعية كاملة أو لا شيء عند التعارض |

الافتراضات: العملة EUR، التأخر أكثر من 7 أيام تقويمية منذ التسجيل كمؤشر داخلي، القنصل مراقب لا يعدل، و«أُعيد» تعني سُلّم للإرسال لا وصل للمواطن. توجد حسابات مدير نظام لتصحيح بيانات التسجيل وإدارة التشغيل.

## تشغيل المطور

```bash
npm ci
cp .env.example .env
# ضع القيم الصحيحة في .env
npm test
npm run build
npm run dev
```

`npm run dev` يشغّل الواجهات والاتصال الداخلي بـSupabase، لكنه لا يشغّل دالة Vercel `/api/track`. لتشغيل المسار العام محليًا استخدم `npx vercel dev` واضبط متغيرات localhost كما في دليل التنفيذ، أو اختبر نشرًا تجريبيًا على Vercel.

## فصل البناء

متغير VITE_APP_MODE يختار نقطة دخول واحدة وقت البناء. كود الموظفين ومكتبة Supabase للمتصفح لا يدخلان في حزمة الجمهور. مشروع الموظفين لا يحتاج أي مفتاح خدمة أو Turnstile. للاستعلام العام تبقى متغيرات الخادم المذكورة في دليل الإعداد مطلوبة.

## نطاق التسليم

هذا كود قابل للبناء والنشر، وليس خدمة منشورة أو اعتمادًا أمنيًا أو قانونيًا للبعثة. لم تُستخدم بيانات حقيقية أو حسابات Supabase/Vercel تابعة لك. الاختبارات المنفذة محلية؛ يلزم تنفيذ قبول تشغيلي بعد الإعداد. الشق الداخلي محمي بحسابات وصلاحيات وMFA، وليس شبكة مغلقة أو VPN. سياسة الاحتفاظ بالبيانات واعتماد الاستضافة المؤسسية تُحدد قبل إدخال البريد الفعلي.
